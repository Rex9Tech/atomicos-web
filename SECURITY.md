# Security Policy & Vulnerability Disclosure

RexOne Web is committed to robust frontend security, XSS defenses, safe token handling, and zero-leak client architecture.

---

## 🏛️ Supported Versions

| Version / Branch | Supported          | Security Maintenance Status |
| ---------------- | ------------------ | --------------------------- |
| `main` / `HEAD`  | :white_check_mark: | Active Security Updates     |
| `dev`            | :white_check_mark: | Pre-release / Nightly Scans |
| Legacy releases  | :x:                | Deprecated / Upgrade to main|

---

## 🚨 Reporting a Vulnerability

**Please DO NOT report security vulnerabilities via public GitHub issues, discussions, or social media.**

To report a frontend vulnerability, cross-site scripting (XSS) risk, or credential leak:
- **Email**: `rex9.tech@gmail.com`
- **GitHub Security**: Use GitHub Private Vulnerability Reporting under repository Security tab.

We acknowledge all reports within **48 hours** and target patches within **7 days** for critical issues.
